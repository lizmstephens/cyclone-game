Gamede (2007): original and reconstructed daily forecasts

This test uses the newly recovered WATTCH forecast runs, rather than the single initialisation previously stored in the main game.

Original means a WATTCH hindcast initialisation. Synthetic means a missing daily briefing reconstructed retrospectively from the preceding and following original initialisations; it is not a genuine issued forecast. The game itself is unchanged.

Method

The missing daily forecasts are calculated by blending each matched member's lead-time-relative displacement and intensity change from the two surrounding WATTCH initialisations. Synthetic members start at the reference-track position on the issue date and fan out as lead time increases. Genuine forecasts are preserved unchanged.

The reconstruction uses a later WATTCH forecast, which would not have been available on the synthetic issue date; this is a training reconstruction, not a historical real-time prediction. The earliest WATTCH runs precede the available reference track and are displayed without a reference-anchored start marker.
