Gamede (2007): daily forecast playtest

Play Gamede using its recovered WATTCH ensemble initialisations, with interpolated forecasts on intervening days. Make mobilisation and activation decisions using the normal game controls.

This is a test scenario. Original WATTCH initialisations are preserved; synthetic daily updates are retrospective reconstructions using surrounding WATTCH runs. The actual storm reference track is used only for the initial position of synthetic forecasts.
